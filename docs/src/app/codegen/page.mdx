# Codegen

Use `codegen` to turn supported successful agent-browser actions into reusable test artifacts. The default format is Chrome DevTools Recorder JSON for the Recorder panel and `@puppeteer/replay`. Use Playwright output when you want a runnable `@playwright/test` spec.

## Workflow

```bash
agent-browser codegen start --title "login flow"
agent-browser open https://example.com/login
agent-browser fill "#email" "a@example.com"
agent-browser click "#submit"
agent-browser isvisible "#welcome"
agent-browser codegen stop ./login.flow.json
```

To emit Playwright instead:

```bash
agent-browser codegen stop ./login.spec.ts --format playwright
```

`codegen` is not [Video Recording](/recording). `record` saves a WebM while `codegen` writes a replayable browser-test artifact.

Direct CSS selectors, <code>xpath=</code> selectors, snapshot refs with accessible names, and uniquely probed test IDs can become safe targets. Codegen omits an action when it cannot produce a safe target. Direct <code>text=</code> selectors, bare XPath, semantic locator marker actions, and most wait variants are not recorded. Other successful mutating or wait commands produce omission warnings. Read all warnings before you use the artifact.

## Security

Typed values are included verbatim for replay fidelity. This includes password values, selected values, and upload paths. The in-progress append-only journal is stored with owner-only permissions in the daemon socket directory, so an unfinished flow survives a daemon restart. Use `codegen status` to inspect warnings and recovery state. Use `codegen discard` to remove the journal. A successful stop removes the journal. Inspect generated artifacts and do not commit credentials.
