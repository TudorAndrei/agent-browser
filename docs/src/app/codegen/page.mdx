# Codegen

Use `codegen` to turn successful agent-browser actions into reusable test artifacts. The default format is Chrome DevTools Recorder JSON, compatible with the Recorder panel and `@puppeteer/replay`. Use Playwright output when you want a runnable `@playwright/test` spec.

## Workflow

```bash
agent-browser codegen start --title "login flow"
agent-browser open https://example.com/login
agent-browser fill "#email" "a@example.com"
agent-browser click "#submit"
agent-browser isvisible "#welcome"
agent-browser codegen stop ./login.flow.json
```

To emit Playwright instead:

```bash
agent-browser codegen stop ./login.spec.ts --format playwright
```

`codegen` is not [Video Recording](/recording). `record` saves a WebM while `codegen` writes a replayable browser-test artifact.

Popup targets and iframe paths are preserved when exporting either Recorder JSON or Playwright.

## Security

Typed values are included verbatim for replay fidelity, including password values. The in-progress append-only journal is stored with owner-only permissions in the daemon socket directory, so an unfinished flow survives a daemon restart. Use `codegen status` to inspect its recovery state and `codegen discard` to remove it. A successful stop removes the journal. Inspect generated artifacts and do not commit credentials.
